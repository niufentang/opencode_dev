深圳证券交易所融资融券业务数据申报通道变更指南
一、 引言
1.1
目的
本指南提供给开展融资融券业务的证券公司（以下简称“证券公司”），用以指导其
每日收盘后通过新的通道向交易所申报有关融资融券余额，及信用违约资料等业务数据；
同时交易所对上报数据文件进行格式检查和内容稽核，对通过新通道反馈的结果文件格
式和内容进行详细说明。
1.2
释义和缩略语
词汇缩写
含义
SZSE-FTS
深交所文件传输系统
1.3
参考文档
《深圳证券交易所融资融券业务券商技术系统变更指南》
《深圳证券交易所数据文件交换接口规范》
以及本所原有的技术系统接口
二、 概述
深市新一代交易系统上线稳定运行后，融资融券业务数据原来的申报通道双向通信
系统将不再接收上报文件，证券公司需通过 SZSE-FTS 文件传输系统进行。 SZSE-FTS
文件传输系统基于深圳证券交易所新一代交易系统交易接入网络实现数据文件传输。在
有效报送时间内，用户可以通过该通道随时上传，如想重传，只需第二次传送的文件大
小或文件时间和第一次不一致即可，第二次会覆盖第一次的文件。
每日收盘后，证券公司应当按照原来约定的业务时间（ 22:00 前）通过 SZSE-FTS
平台申报数据文件，申报文件名和文件格式同原来一致，文件内容接口保持不变。证券
公司 22:30 收到数据稽核短信后，如果需要重报，应当通过会员专区走应急申报流程。
证券公司通过 SZSE-FTS 申报文件，交易所收到文件后首先会进行文件格式检查，
检查结果通过该通道直接返回给对应的证券公司，反馈文件接口详细描述见下文数据申
报部分。
格式检查通过后，交易所将继续对融资融券业务数据内容进行稽核检查，检查结果
通过 SZSE-FTS 平台直接返回给对应的证券公司，同时，与现行的方式相同，各证券公
司也可以通过会员专区即时查询稽核结果，具体查询路径为：“会员业务专区” - “公文
及报表上传” - “融资融券” - “每日稽核结果查询”。融资融券业务数据的稽核规则跟
原来保持一致。

三、 数据申报
3.1
融资融券余额数据申报
申报文件名为 XYnnnnnn.DBF , 其中 nnnnnn 为融资融券专用交易单元代码，文件
接口保持不变，申报内容遵循原来的规则。证券公司通过 SZSE-FTS 平台申报该 DBF
文件，交易所收到文件后首先对 DBF 文件格式进行检查，如果格式检查错误，则通过
FTS 回传 *.err 文件 ( 通配符“ * ”代表源文件名不带扩展名的部分 ) ，其中包含具体格式
错误描述。
如果格式检查无误，交易所会进一步对融资融券余额数据内容进行稽核，稽核规则
跟原来保持一致。如果稽核未通过，则通过 FTS 回传 *.err 文件，错误原因填写“余额
数据未能通过稽核”，并同时通过该通道回传 *.DBF 文件给对应证券公司，提供未能通
过稽核的数据和原因。证券公司收到错误反馈文件后及时排查错误原因，并重新向交易
所发送数据文件。
如果格式检查和内容稽核均通过，则回传 *.suc 文件，内容为空，表示当日融资融券
余额数据成功申报。
格式反馈文件 *.suc 和 *.err 的文件名为 XY_YYYYMMDD_nnnnnnss 文件，其中
YYYYMMDD 为当前日期， nnnnnn 为融资融券专用交易单元代码， ss 为发送序号，避
免多次发送文件覆盖，序号最大的为最新发送的结果。
错误反馈文件 *.err 为 xml 文件，其内容格式如下：

四、 数据申报时间约定
交易所对券商通过 SZSE-FTS 申报文件有效的处理时间为交易日下午 15:30 到 22:00 ，
重报仍然通过会员专区进行，重报流程保持跟原来一致。非 SZSE-FTS 有效报送处理时
间段申报文件，将会反馈错误信息。
每个交易日 15:30 至 22:00 期间，证券公司可以通过 SZSE-FTS 通道向交易所多次
重发源文件，交易所对重发的文件执行同首次接收文件一样的处理流程，交易所以最后
一次接收到的文件为准。

五、 通道开通说明
已开展融资融券业务的证券公司，本次通过 SZSE-FTS 上传文件，需要新开通一个
文件传输规则，在交易所会员 BPM 系统上发起开通流程，具体参见《深圳证券交易所
新一代交易系统业务网关办理指南》中的“文件通信网关配置变更”流程。针对“融资
融券业务”上报文件，传输规则是这么约定的： szse_riskcontrol_<nnnnnn> ，其中 <nnnnnn>
是会员的 6 位会员编号。
六、 并行运行期间数据申报说明
为确保新旧报送通道平稳过渡，新一代交易系统上线初期，将安排一段并行运行期
间，该期间内证券公司可以选择通过旧的通信小站报送或者新的 SZSE-FTS 通道报送。
选择通过旧通道报送数据的证券公司收到数据反馈的方式同原来一致，仅能够通过会员
专区查看数据稽核结果，通信系统自动下发违约汇总资料；选择通过新通道报送数据的
证券公司将在新的通道收到数据反馈结果，同时也可以在会员专区查看数据稽核结果。
建议各证券公司当天只选择一条通道报送数据，如果两条通道同时报送数据，且数
据恰好同时收到，可能会造成数据混淆。如果两条通道都有收到数据，交易所将不区分
通道来源，收到文件后向新旧通道同时发送反馈数据文件，多次发送将会以最后一次收
到的数据文件为准。
并行运行期间开始时间以新一代交易系统上线时间为准，并行时间约为半年。并行
运行结束后，旧的通信系统将不再使用，全部通过新的通道申报数据，请证券公司提前
做好切换工作。并行运行的结束时间，由交易所另行通知。
七、 风险提示
实时数据稽核结果反馈响应时间为 5 分钟之内，若证券公司超时未收到反馈结果，
请及时联系交易所相关负责人员。
由于 SZSE-FTS 通道可以随时上传数据，多次上传会覆盖前次上传数据，在数据申
报有效时间段内，交易所会以最后一次报送的文件数据为准。
