关于做好欣泰电气欺诈发行先行赔付实施相关
技术准备的通知
各会员及相关单位：
2017 年6 月9 日，中国证券投资者保护基金发布《中国证
券投资者保护基金有限责任公司关于欣泰电气欺诈发行先行赔
付专项基金的管理人公告》。为确保赔付工作的顺利实施，深圳
证券交易所（以下简称“深交所”）联合中国证券登记结算有限
责任公司深证分公司（以下简称“中国结算深圳分公司”）拟采
用网络投票业务实施本次赔付工作。现将有关技术系统准备事项
通知如下：
一、 本次赔付借用深交所网络投票业务实施，赔付权证
券代码为“369401”，证券简称为 “欣泰赔付”。本次赔付权
证券代码及简称将在赔付实施完毕后根据基金管理人申请予以
注销。
二、 中国结算深圳分公司根据专项基金管理人的申请及
其提供的适格投资者明细，向适格投资者所在的证券公司下发其
赔付权。赔付权明细通过SJSJG.DBF 中JGYWLB='TGXG'的数据下
发至各证券公司，赔付权证券代码为369401，每一份赔付权对
应赔付金额为1 元人民币。
三、 赔付权申报通过交易接口的网络投票委托申报
（STEP：U004，Binary：102197），具体指令定义参见《深圳证

券交易所Binary 交易数据接口规范（Ver1.02）》、《深圳证券
交易所STEP 交易数据接口规范（Ver1.02）》，其中指令消息的
OrderQty（投票数量）字段填写赔付金额（如赔付金额为13004
元，则STEP 接口填写13004.00、Binary 接口填写1300400），
填写的金额应严格等于通过“欣泰电气欺诈发行先行赔付专项基
金”专栏查询的赔付金额。在申报期间，适格投资者可以在全市
场任意开户券商处申报赔付。
同时，会员也可以引导投资者登录深圳证券交易所互联网投
票系统进行申报(网址 <span style="color:blue">http://wltp.cninfo.com.cn</span> ) ，选择互
联网投票系统首页左边栏图标“欣泰电气欺诈发行先行赔付专项
基金赔付申报”通过互联网系统进行赔付申报。
四、 赔付权申报期间，深交所每个交易日通过网络投票
回报文件（evotereport_YYYYMMDD.csv）向会员发送赔付申报首
日至当日所有赔付权申报指令的处理结果。
网络投票回报文件中，针对“欣泰赔付”申请委托指令的
处理结果，其对应的错误代码仍为OrdRejReason 字段，错误代

总清算数据将于赔付资金派发日前一交易日通过清算数据

券代码字段显示为300372。

系统可以根据投资者真实意愿，准确提交赔付申报指令，并确保
适格投资者通过证券公司技术系统可完成下列事项：
（1）查询投资者自身的赔付权数据；

（3）查询、使用并提取成功申报的赔付资金。
