一、 服务说明
1.1
服务定义
成交汇总服务是深圳证券交易所（以下简称“深交所”）为市场各类主体提
供的用于接收成交汇总数据的附加服务，满足用户在集中托管、集中清算和数据
备份等方面的附加需求。主要服务对象为两类：参与市场交易的交易参与人和为
市场其他主体提供托管服务（如基金托管行）的托管人。
 交易参与人
交易参与人可使用成交汇总服务接收该交易参与人名下不同类别的成交汇总
数据，满足交易参与人实现集中清算、数据备份等多种需求。
 托管人
深交所根据产品管理人（委托人）的授权下，为基金托管行等托管人提供成
交汇总服务，允许托管人直接从交易系统接收产品管理人的成交汇总数据，为托
管人提供了非常便利的获取成交数据的通道，便于托管人为其委托人进行集中清
算和集中托管。
1.2
服务约定
交易参与人、托管人等市场相关单位使用成交汇总服务，默认遵守本指引、
依照本指引规范自身行为。
交易系统提供流接口和文件接口两种形式的成交汇总数据服务。市场各相关
单位可自行选择通过成交汇总通信网关实时接收流格式成交汇总数据，或在收市
后通过文件通信网关接收文件形式成交汇总数据。
作为为市场提供的一种附加服务，深交所尽力保障服务正常运行，但可能会
在后台软硬件异常、线路故障等极端情形下暂停服务，对相关单位可能的业务影
响不承担责任，各相关单位应做好技术备份或其它应对措施、确保业务不因成交
汇总服务的暂停受到影响。

二、 服务规范
1. 相关单位应遵行深交所交易系统接入服务技术规范（以下简称“接入服务
技术规范”）（详见深交所官网 => 市场服务 => 技术服务 => 技术专栏 => 技术指南 =>
《会员及其他相关单位访问深交所交易系统接入服务技术规范》）要求访问深交
所交易系统的成交汇总服务。对于不符合或违反此接入服务技术规范的，深交所
有权暂停或终止为其提供成交汇总服务，相关单位自行承担相应责任。
2. 非会员单位使用成交汇总服务获取成交数据为其客户提供其他技术服务，
应做好其不同客户成交数据的隔离、确保客户成交数据的保密性和安全性。
三、 异常处理
1. 单节点网络故障或服务故障
深交所在福田节点和南方节点同时提供接入服务，用户需为成交汇总通信网
关、文件通信网关同时配置两个接入点的接入服务 IP 。当某个节点的网络或服务
出现故障后，成交汇总通信网关、文件通信网关会自动切换至可用的节点。
2. 用户系统故障导致成交汇总数据丢失
深交所文件传输服务提供重传功能，用户可通过文件通信网关重新获取文件
接口形式的成交汇总数据，目前最多可重传 10 个自然日以内的成交汇总数据文件，
实际可重传范围应以交易所网站公布的日期为准。
3. 成交汇总数据服务异常
成交汇总数据服务本身在极端情形下也可能出现异常，建议用户可考虑：
1 ） 同时申请流接口和文件接口两种服务，两种方式互为备份；
2 ） 同时，在两种接口服务均出现异常时，用户还可采用其他方式获取成交汇
总数据：
 交易参与人可从其普通交易网关接收的成交数据自行汇总
 托管人可从产品管理人处接收成交数据并进行汇总

五、 业务办理
5.1
业务开通指引
申请单位登录深交所会员业务专区系统提交申请；托管人等不能登录会员业
务专区的申请单位请向深证通提交书面申请，托管人应在申请时一并提交产品管
理人的书面授权文件。
申请步骤如下：
1. 新建成交汇总通信网关；
2. 开通成交汇总通信网关；
3. 如需接收文件接口成交汇总数据，则通过文件通信网关（如没有则需申请
新建）配置变更，申请开通“盘后成交汇总文件接收”功能；
4. 交易单元有变化时，通过成交汇总通信网关配置变更，新增或删除交易单
元。
上述各步骤的详细办理流程和申请资料参见深交所官网 => 市场服务 => 技术服
务 => 技术专栏 => 技术指南 => 《深圳证券交易所交易系统网关业务办理指南》。
5.2
网络配置指引
1. 参照《交易结算系统用户网络接入方案》中的“交易接入网”章节选择接
入方式、确定带宽需求。
2. 参照《交易结算系统用户网络接入方案》中的“用户接入指引”章节进行
网络配置，仅使用成交汇总服务的用户不需要进行“接入路由器组播路由配置”
相关的调整。
3. 深交所提供了与各网络运营商的合作框架协议，具体详情参见《深圳证券
交易所新一代交易系统专线合作框架协议》。
